# Video Platform Web Client

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run dev

# production mode
$ npm run build

# preview production build
$ npm run preview
```

## Run tests

```bash
# unit tests
$ npm run test:unit

# e2e tests
$ npm run test:e2e

# e2e tests (dev mode with UI)
$ npm run test:e2e:dev

# full e2e tests (with docker backend)
$ npm run test:e2e:full
```

## Lint files

```bash
# analyze and fix files
$ npm run lint
```

## Format files

```bash
# format files with prettier
$ npm run format
```
